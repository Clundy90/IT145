# IT145 Coursework

This repository contains my coursework for IT145: Introduction to Java Programming.

The assignments show my progress with Java fundamentals, including classes,
inheritance, constructors, encapsulation, user input, loops, validation, and
basic calculations.

The projects include small pet and dog-management programs, paint calculators,
and a larger Grazioso Salvare rescue-animal application. The Grazioso program
allows users to add dogs and monkeys, reserve animals, and view animals in the
system or available for service.
